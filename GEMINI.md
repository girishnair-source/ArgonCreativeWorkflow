# Zero-Touch Creative Editor Mode (Mandatory Workspace Rules)

The user operating this workspace is a **Creative Video Editor / Director**, NOT a software engineer.
Follow these rules strictly on every turn:

1. **NEVER Ask the Editor to Run Python, Virtual Environments, Git, or Terminal Commands**:
   - You (Antigravity) must execute all terminal commands, Git clones/pulls, Python scripts, environment setups, and DaVinci Resolve sync triggers yourself using `run_command`.
   - If the editor starts with a GitHub source URL (e.g., *"Start a new production in AGY Studio using this source : https://github.com/girishnair-source/ArgonCreativeWorkflow.git"*) and `agy_studio/` is not yet present in the current working directory, automatically clone or sync that repository into the workspace first via `run_command`.
   - If `.venv`, `ffmpeg`, or `gcloud` are missing or unauthenticated, automatically run `bash setup_studio_env.sh` via `run_command`. If Google Cloud needs authentication, run `gcloud auth login` and `gcloud auth application-default login` via `run_command` so the Google sign-in browser window pops open automatically for the editor, or tell them the single command `gcloud auth login` only if needed.

2. **Interactive Creative Intake — Mandatory Gate at Project Start (Use `ask_question` in Plain Filmmaking Language)**:
   - Whenever the editor starts a new project (whether via *"Start a new production in AGY Studio using this source : https://github.com/girishnair-source/ArgonCreativeWorkflow.git"* or *"Start a new production in AGY Studio and guide me step by step from script to Final Edited Video"*), first silently verify the environment (`live_demo_preflight.py` / `setup_studio_env.sh`), and **MUST FIRST** ask via `ask_question` to lock the **Operating Mode**, **Format**, **Language**, **Production Scope**, **3D Blocking Engine**, and **Reference Sheet Reuse**, and prompt the editor for their **Project Title, Project ID (optional — auto-derived from title if omitted), and Script / Story Brief**:
     1. **Operating Mode (The 3 Studio Modes — `ControlMode`)**:
        - **Mode 1 — `director` (Ultimate Director Control)**: Human review and explicit approval at every single gate (`G1` Global Bible $\rightarrow$ `G2` Character/Location Sheets & 3D Set $\rightarrow$ `G3` Storyboard & 3D Camera Angles $\rightarrow$ `G4` Voice Auditions $\rightarrow$ `G5` Video Takes $\rightarrow$ `G6` DaVinci Resolve Scene Cut).
        - **Mode 2 — `hybrid` (Smart Hybrid Control)**: Stops at core creative gates (`G1` Global Bible, `G3` Storyboard/3D Framing, `G5` Video Takes, `G6` Resolve Cut), while auto-passing `G2` and `G4` whenever approved Global Bible character sheets, sets, or locked voice prints are reused.
        - **Mode 3 — `autopilot` (Seamless End-to-End Autopilot)**: Approve `G1` (Global Bible) once, and AGY Studio runs `G2` through `G5` autonomously with Critic QA self-healing (`threshold >= 0.85`), pausing only at `G6` when the assembled DaVinci Resolve timeline is ready.
     2. **Content Format & Aspect Ratio (`ContentFormat`)**:
        - Ask whether the project is a **Vertical Microdrama (`microdrama_9_16`, `9:16`)**, **20-Minute Episode (`episode_16_9`, `16:9`)**, **Feature Film (`feature_film`, `16:9` / `2.39:1`)**, **Multi-Shot Commercial / Marketing Spot (`marketing_spot`, time-coded beat escalation)**, or **2D/3D Cartoon**.
     3. **Primary Dialogue Language, Production Scope & Script Intake**:
        - Ask for the **Primary Language** (e.g., `Hindi / Hinglish`, `English`, `Tamil / Telugu / Regional`) via `ask_question`.
        - Ask for the **Production Scope** via `ask_question`:
          - `(Recommended for Live Demo) Pilot Scene 1 Only (SC01 — 3 to 4 shots, fast 8-min end-to-end to Final Edited Video & DaVinci Resolve)`
          - `Full Script (All Scenes in the Screenplay)`
        - If the user has not yet shared their **Project Title**, **Project ID** (auto-generate a clean ID like `AUDIENCE_EP01` if not provided), or **Script / Story Brief**, ask them in plain English to paste their script or story beats right after submitting the intake modal.
     4. **3D Camera Blocking Engine & Token-Saving Reference Sheet Gate (`casting_agent.py` & `set3d`)**:
        - Ask **whether the Director wants a 3D blocking set at all** — options: **No 3D set (default — fastest, cheapest)**, **Browser 3D FPV (`set3d serve`, no Blender needed)**, **Native Blender (`set3d open-blender`)**, or **Both**. 3D world building costs an LLM design pass + Blender export/render per location and is useful only when a human wants to walk the room and frame cameras.
        - Before generating ANY character or location images, ALWAYS ask:
          *"Do you already have Character Reference Sheets or Location Reference Images for these characters/settings? (If yes, drop them into this folder or share their filenames so we reuse them and save tokens; otherwise I will generate new ones for you.)"*
        - **3D sets are NEVER built automatically in any mode** (the engine does not do it at G2 either). Only when the Director chose a 3D option at intake — or asks later — run `.venv/bin/python -m agy_studio set3d build <ENV_ID>` and then show it: `set3d open-blender <ENV_ID>` (opens Blender GUI with the set built live, saves `<ENV_ID>.blend`; add `--render` for headless `.blend` + `cam_renders_9_16/<CAM>_3d_clean.png`) and/or `set3d serve <ENV_ID>` (browser FPV). If Blender is missing the command stops with the install hint — never fake a render. When re-anchoring off-axis/OTS shots from 3D screenshots, always use `compute_view_space_blocking_summary` + isolated character crops so wide-master backgrounds never bleed into OTS angles.
     5. **Human-Paced Single-Speaker Dialogue Gate (`dialogue_agent.py`) & Exact Native Script Mandate**: Automatically write or validate all scene dialogue so that:
        - Every line fits human speaking pace (`8–14 words` per 8s shot, `5–8 words` per 5s shot, with `0.6s` pre/post-roll breath cushions).
        - Every character's acoustic voice print (`CharacterVoiceProfile`) stays identical across every shot and episode.
        - **Native Script Dialogues (Any Language)**: Always write and request prompts using the exact dialogue in its **authentic native script** alongside phonetic transliteration when helpful.
        - **Voice-Over vs. On-Camera Lip-Sync Gate**:
          - **Voice-Over / Off-Screen / Narrator / Phone Audio (`off_screen=True`)**: **ALL visible characters' mouths must remain 100% SHUT (`CLOSED`)**.
          - **On-Camera Dialogue (`off_screen=False`)**: **Only the intended speaking character lip-syncs properly** to the line, while all other visible characters in the frame keep their mouths `100% CLOSED`.

3. **Primary Media Generation Tier — Nano Banana Pro (14 References) & Gemini Omni 1.1 / Vertex Veo 3.1**:
   - **Keyframes & Reference Sheets**: Default to **Nano Banana Pro (`gemini-3-pro-image`)** on Vertex AI, passing **up to 14 reference images** simultaneously (`compiled_shot.reference_image_paths` — character turnarounds, expression sheets, location plates, hero props, style bible, and preceding scene shots), or built-in `generate_image` (up to 3 refs).
   - **Video & Dialogue Clips**: Default to **Gemini Omni 1.1 (`gemini-omni-1.1-flash`)** (up to 10 reference images + 3 reference videos, native **1080p/4K**, **4–10s** durations, and **`extend_video`**) or **Vertex AI Veo 3.1 (`veo-3.1-generate-001`)** via [`vertex_veo_director.py`](./vertex_veo_director.py).
   - **Cinematic Multi-Shot Staging**: Stage and prompt scenes as dynamic cinematic multi-shot sequences (e.g. `[Beat 1: 0s-4s Master / OTS Angle] -> [Cinematic Cut at 4s to Beat 2: Reverse Reaction Close-Up]`) to maximize dramatic pacing and visual momentum.

4. **Zero-Click Final Edited Video (`.mp4`) & DaVinci Resolve Dual Delivery**:
   - Write all story/character/scene specs into Python modules yourself behind the scenes.
   - Generate the keyframes, voice stems, and video clips yourself.
   - At **Gate G6**, ALWAYS deliver **BOTH**:
     1. **A Standalone Final Edited Master `.mp4` Video** (`productions/<PROJECT_ID>/post/<PROJECT_ID>_FINAL_EDITED_VIDEO.mp4`, loudnormed to `-14 LUFS` with dialogue, room tone, foley, and ducked score mixed together) so the Director and audience can play the finished movie immediately.
     2. **An Editable 5-Track DaVinci Resolve Timeline** (`SC01_v1` / `MASTER_v1` with `V1` picture, `A1` dialogue, `A2` room tone, `A3` foley, `A4` ducked score, subtitles, and QA markers) pushed automatically into DaVinci Resolve.

5. **Live Audience Demo Deterministic Anti-Hallucination Contract (`G0` → `G6`)**:
   - **Never Auto-Approve Gates Behind the Scenes**: In `director` or `hybrid` mode, NEVER run `gate G1 "approve all"`, `gate G2 "approve all"`, or `gate G3 "approve all"` until you have FIRST presented a visual review artifact (`g1_bible_review.md`, `g2_visual_review.md`, `g3_storyboard_review.md`, `g5_video_takes_review.md`) containing embedded PNG/JPG images and clickable `[filename](file:///...)` links, AND received the Director's explicit approval.
   - **Single-Source-of-Truth Reference Chain (Zero Character/Room Drift)**:
     - At **Gate G2**, always embed and verify every character's canonical `front.png` + `face_closeup.png` and every environment's `cam_WIDE_MASTER.png` in `g2_visual_review.md` so no stale/mismatched packs exist.
     - At **Gate G3**, every storyboard keyframe generation MUST pass the locked reference anchors: `(1) Approved G2 Master Room Plate (cam_WIDE_MASTER.png)` + `(2) Approved G2 Character Sheet(s)` + `(3) the 3D Camera Blockout PNG (cam:<NAME>_3d_clean.png)` **only if the Director opted into a 3D set** — NEVER generate a shot from text alone, and NEVER build a 3D set just to obtain anchor (3).
   - **Visible 3D World — on request only**:
     - When (and only when) the Director asked for a 3D set, make it visible: `set3d open-blender <ENV_ID>` puts the room, lights, mannequins and every saved `CAM_<NAME>` on the Director's screen in Blender and saves `<ENV_ID>.blend`; `set3d open-blender <ENV_ID> --render` additionally renders every camera blockout; `set3d serve <ENV_ID>` opens the 60 FPS browser FPV. Report the `.blend` path and the rendered PNGs. Never run these as a side effect of a gate.
   - **Sequential Subagent Guard & PATH Guard**:
     - Always prepend `/opt/homebrew/bin:/usr/local/bin:/opt/homebrew/share/google-cloud-sdk/bin` to `PATH` when invoking `ffmpeg`, `gcloud`, or `blender` (the Python harness does this itself via `agy_studio/adapters/auth.py`; set `AGY_GCLOUD=/full/path/to/gcloud` for custom installs).
     - When invoking `image-generator` subagents, run **1 subagent at a time** (or up to 3 images inside a single subagent) to prevent concurrent `429 RESOURCE_EXHAUSTED` rate-limit errors during a live demo.
   - **Two-Tier `360p` Draft → `3×3` Contact Sheet Critic → `4K` Finalize (`Gemini Omni 1.5 Flash` + `Gemini TTS 3.8`)**:
     - At **Gate G4**, use **Gemini TTS 3.8 (`gemini-3.8-tts`)** with native script dialogue + `[acoustic delivery tags]` intact (never ElevenLabs).
     - At **Gate G5**, generate `360p` draft video takes first, run `build_3x3_contact_sheet()` + `VisualContinuityCritic` (9 frames across the whole take; static/slideshow takes are hard-rejected), and promote the winning take to `4K` reusing the **exact same prompt, seed, and reference bundle** (`reuse_prompt_on_finalize=True`), then assemble both the **Final Edited `.mp4` Video** and the **5-track `-14 LUFS` DaVinci Resolve Timeline** at **Gate G6** with `StateTokenGuard` and `TimelineGitRepo` commit history.

6. **Fail-Fast Credential Contract — NO Offline Fallbacks, EVER (`agy_studio/adapters/auth.py`)**:
   - Every real generation call (Gemini Omni / Veo video at `G5`, Gemini TTS at `G4`, Nano Banana Pro images, Lyria music, Gemini text/ASR/vision judges) is authenticated with the local `gcloud auth print-access-token`. The built-in `image-generator` subagent uses Antigravity's own credentials, so **"G3 images worked" proves NOTHING about G4/G5** — always run `.venv/bin/python live_demo_preflight.py` (which actually mints a token) before `G4`.
   - When any step raises `AuthError` / prints `STOPPED — Google Cloud sign-in problem`, **STOP IMMEDIATELY** and paste the complete message to the Director verbatim (it already contains gcloud's real error and the exact fix, e.g. `gcloud config set context_aware/use_client_certificate true` + `gcloud auth login` + `gcloud auth application-default login`). Run those commands via `run_command` (the browser sign-in opens for the editor), then re-run the **same** gate command — the `auth` blocker clears itself on the next tick.
   - **FORBIDDEN while a credential problem is open** (these waste minutes, produce unusable output and hide the real block): any fake / offline generation backend (none exists in the product — do not try to add one), macOS `say` / `espeak` / any offline TTS, `ffmpeg zoompan` / Ken-Burns stills or slideshows passed off as video, writing ad-hoc `prepare_g4_*.py` / `prepare_g5_*.py` / "workaround" scripts, retrying with new seeds, or switching provider models. The only fix for a credential error is a credential fix.
   - Never hard-code or guess a GCP project: `VERTEX_PROJECT_ID` / `GOOGLE_CLOUD_PROJECT` or `gcloud config get-value project` must resolve, otherwise the harness stops with the `gcloud config set project <ID>` instruction. To demo on a non-corporate account set `AGY_GCLOUD_ACCOUNT=<account>` (or `gcloud config set account <account>`).

7. **Autopilot Mode Contract (`control_mode=autopilot`) — Script → Editor with ONE Human Click**:
   - The Director approves **G1 only**. From there `tick` / `advance` runs `G2 → G3 → G4 → G5 → G6` with no questions and no waiting gates: missing reference images are generated immediately (no "do you have reference sheets?" prompt), G2/G3/G4 packets are opened for the audit trail and answered by AGY (`source=autopilot`), G5 picks the QA-recommended take per clip and sets first voice anchors itself, and the scene cut is pushed into DaVinci Resolve at `G6`.
   - **No 3D set is built in autopilot** (as in every mode, 3D is opt-in only — `set3d build <ENV_ID>` / `set3d open-blender <ENV_ID>` on request).
   - Do NOT call `ask_question` between G1 and G6 in autopilot, and do NOT stop to present `g2_visual_review.md` / `g3_storyboard_review.md` for approval — present the finished `G6` timeline and the review folders (`scenes/<SID>/review/`) afterwards instead.
   - The fail-fast credential contract (rule 6) still applies: the only thing that may stop an autopilot run is an `AuthError`, which must be shown verbatim and fixed — never worked around.

8. **Gate 4 = Voice SPEC Lock (No Audio Generation) & Gate 6 = Clips IN DaVinci Resolve (Mandatory Deliverable)**:
   - **G4 does not synthesise any audio.** Gemini Omni / Veo render the speech natively while generating the clip; the only voice input they receive is the locked `VoiceProfile.description` (sex/age register, timbre, pitch band, pace, language/accent) that `prompt_engineer` writes into every dialogue line's `voice` field. Never run TTS, macOS `say`, or tone/pitch "audition" WAVs at G4 — the real acoustic anchor is the dialogue of the first approved take, extracted from genuine model output.
   - **G6 is only done when the clips are inside DaVinci Resolve.** `agy_studio` delivers through `FailoverTransport`: (1) the Lua bridge + menu click (`AGY_Bridge.lua`), then (2) the direct `DaVinciResolveScript` scripting API. The DaVinci MCP server is a convenience for *you*, not the delivery path — if MCP is down or errors, do NOT stop: run `.venv/bin/python -m agy_studio advance <SID>` (or `tick`) and the engine pushes the cut itself.
   - If both automatic routes fail, the engine blocks G6 with the exact cause and the manual one-click route (`Resolve -> Workspace -> Scripts -> Utility -> AGY_Bridge`), while the finished `.mp4`, OTIO/FCPXML and staged take media are already on disk under `post/` and `scenes/<SID>/assembly/`. Relay that message verbatim, fix the cause (Resolve open? external scripting = Local? Accessibility permission?), then `unblock <SID>` + `advance <SID>` — nothing is regenerated.

9. **Model Policy Is Configuration, Not Code**:
   - Global capabilities and default fallback chains live in `agy_studio/registry.yaml` (hot-reloaded). Per-production choices live in `productions/<ID>/project.yaml` → `settings.video_model_primary`, `settings.video_model_secondary` (`none` = fail fast on the primary, no engine fallback), `settings.provider_fallbacks` (per registry id; empty list = primary provider only) and `model_pins`.
   - Set or inspect them with `.venv/bin/python -m agy_studio models [--primary omni|veo] [--secondary omni|veo|none|auto] [--fallback ID=a,b] [--clear-fallbacks]`; per-scene `model <SC> <id>` still overrides the production primary. If the Director names a preferred engine at intake, persist it with `models --primary …` immediately — never hard-code a model id in prompts or scripts.

10. **The 3×3 Contact Sheet Is a Measurement, Not Decoration**:
   - `build_3x3_contact_sheet` tiles 9 frames spread evenly across the WHOLE take; `VisualContinuityCritic` and the QA critic measure frame-to-frame motion on it. Nine identical tiles = a still image padded into an mp4 (storyboard + `ffmpeg zoompan`, slideshow) → hard reject `static_frames` / `static_video`, and a take with no provider `operation_name` behind its file is `unprovenanced_video` → hard reject. No human/LLM check can override these.
   - Never produce a "take" by any means other than the video adapters (Omni / Veo through `generate_clip` / `advance`). `python -m agy_studio contact-sheet <take.mp4>` prints the motion numbers and the critic verdict if you need to inspect one.
