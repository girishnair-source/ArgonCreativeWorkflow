# Tier-0 Generic Filmmaking & Multi-Shot Commercial Bible (`generic_bible.md`)

These built-in domain rules govern every scene, shot, and video prompt generated by AGY Studio across **Long-Form Films**, **Episodic Shows**, **Vertical Microdramas (`9:16`)**, and **Multi-Shot Commercials / Marketing Spots**.

## 1. Seven-Layer Visual Scene Description (Mandatory in Every Shot Prompt)
Every keyframe and video prompt must explicitly specify all 7 layers (never vague captions):
1. **Subject**: Named directly with concrete visual descriptors (e.g., `"CHAR_RISHI, a 22-year-old Indian man in a charcoal-grey hoodie"`, never ambiguous pronouns).
2. **Context**: Exact architectural/environmental setting resolved from `SceneBible -> GlobalBible`.
3. **Action**: Specific physical movement and micro-expressions.
4. **Style**: Locked aesthetic from `STYLE_LOCK`.
5. **Camera**: Explicit camera motion (`static tripod`, `slow push-in dolly`, `tracking`, `handheld`, `orbit`).
6. **Composition**: Shot size and angle (`wide establishing`, `medium over-the-shoulder`, `85mm close-up`, `low hero angle`, `shallow depth of field`).
7. **Ambiance**: Key light direction, color temperature, and atmospheric texture.

## 2. Four-Layer Audio & Anti-Subtitle Rules
Every native-audio video generation prompt must specify all 4 audio layers so the model never hallucinates studio-audience laughter or baked-in subtitles:
1. **Dialogue**: Colon syntax (`CHAR_RISHI says: "..."`) in authentic native script (e.g., Devanagari for Hindi) within the `2.2 wps` (`0.6s` pre/post-roll) speech budget.
2. **Ambient Sound**: Explicit room tone / environmental soundscape.
3. **Sound Effects**: Specific action foley (`rustle of silk`, `cardboard tearing`, `hiss of atomizer`).
4. **Music**: Explicit cue description or `"No background music."`
5. **No Subtitles**: Always append `(no subtitles) No subtitles.` and enforce single-speaker lip-sync (`ONLY the active speaker moves their mouth; all other visible characters keep mouths 100% CLOSED`).

## 3. Multi-Shot Commercial & Time-Coded Beat Escalation
When staging commercials, brand spots, or multi-beat microdrama clips (`8–15s`), use explicit time-coded beats and transition language (`Hard cut to`, `Seamless morph into`, `Whip pan to`, `Snap cut to`, `Seamless pull-out to`):
- `(0-3s)` **Macro / Establishing Hook**: Introduce hero subject/product in tactile lighting with shallow depth of field.
- `(3-7s)` **Gliding Medium Interaction**: Camera glides closer as subject interacts physically with the hero object + crisp foley.
- `(7-12s)` **Hard Cut to Slow-Motion Detail**: Peak kinetic/emotional micro-action in slow motion with rim light and synchronized SFX.
- `(12-15s)` **Seamless Pull-Out to Hero Frame**: Centered iconic composition, volumetric lighting, resonant finish.

## 4. Strict 3-Tier Bible Lookup Rule
When resolving any character look, prop, or location plate for a shot:
1. **First**: Check **Scene Bible** (`scenes/<SC>/scene_bible.yaml`) for scene-specific costume/injury/lighting overrides.
2. **Second**: Check **Global Context Bible** (`bible/global_context_bible.yaml`) — Global Bible remains strictly intact during scene edits.
3. **Third**: If still missing, **ask the user** (`ask_question` / `QuestionLog`) — never hallucinate an unanchored asset.
